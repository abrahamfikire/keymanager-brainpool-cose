┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              DATA FLOW SUMMARY                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘

1. CLIENT → HTTP Request with RequestWrapper<RequestDto>
2. CONTROLLER → Validates input, unwraps DTO, delegates to service
3. SERVICE → Business logic, calls KeymanagerService for certificates
4. KEYMANAGER → Retrieves certificates and keys from HSM/KeyStore
5. HSM/KEYSTORE → Provides secure cryptographic operations
6. CRYPTO → Performs signature generation/verification
7. SERVICE → Returns ResponseDto with signed data
8. CONTROLLER → Wraps in ResponseWrapper, sends HTTP response
9. CLIENT → Receives signed data or verification result
